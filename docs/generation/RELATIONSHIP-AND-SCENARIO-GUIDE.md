# Relationship and Scenario Guide

## Relationships create data

A relationship list is not enough. Let relationships produce mentoring, disagreement, encouragement, assignments, correction, prayer, shared work, comments and changed behavior.

Preserve biblical relationships first: Moses/Joshua, David/Saul/Jonathan/Abigail/Nathan/Joab/Solomon, Elijah/Elisha, Paul/Barnabas/Timothy/Titus, Priscilla/Aquila/Apollos, Peter/John and others.

Cross-era 2026 relationships may then enrich the shared organization: Moses can coach overloaded leaders; Nehemiah can help teams define ownership; Barnabas can support recovering leaders; Esther and Deborah can contribute to sensitive leadership situations; Cris can mediate without becoming omniscient.

## Scenario construction

A strong scenario has:

1. an occasion or trigger;
2. people with distinct perspectives;
3. one or more Oikonomia artifacts;
4. decisions/actions;
5. consequences in later records;
6. biblical memory or truth where relevant;
7. visibility/permission appropriate to the subject.

## Canonical shared artifact

When several people attend one meeting, create one canonical meeting artifact. Participants may have personal notes or later reports, but do not duplicate the shared minutes as separate competing versions.

## Continuity examples

- Meeting concern → task assigned → task remains open → attention appears → assignee reports progress → owner closes or escalates.
- Lifegroup prayer request → private pastoral follow-up → restricted report → later testimony.
- Mentoring discussion → development goal → practice opportunity → feedback → later progress review.
- Ministry problem → operational report → cross-ministry coordination → next-week status.

## Perspective

Different people can remember or interpret the same current event differently without changing objective facts. Use comments and personal reflections for perspective. Do not distort biblical facts for dramatic tension.

## Cris

Cris is a leadership coordinator/mediator, not a superior to Moses, David, Peter or Paul and not an all-access narrator. Use Cris to connect modules and unresolved cross-ministry work when appropriate.
