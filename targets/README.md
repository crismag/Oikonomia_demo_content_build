# Character Generation Targets

This directory is the working backlog for Data Play character generation.

Each character gets a separate target file containing identity, role/ministry possibilities, biblical topic coverage, relationships, Oikonomia record opportunities, sensitivity/humor notes and status.

These files answer **what should be generated for this character**. They are not canonical character content and are not intended for Oikonomia import.

Finished content belongs under `/characters/<character>/`.

Use `GENERATION-QUEUE.md` for the roster and progress view. Before generating a target, read `/docs/generation/README.md` and the target file. Update the target status/checklist as content is completed.

Status vocabulary: `NOT STARTED`, `IN PROGRESS`, `FOUNDATION EXISTS`, `SUBSTANTIAL`, `COMPLETE`, `DEFERRED`.

A target may remain open even when substantial content exists if major biblical relationships or record families are still missing.
